# 1.0.0 — Initial Release (in progress)

- Get Rows / Read Range: fetch rows from a sheet, keyed by header name, with optional single-column filtering.
- Search Rows: find row(s) by exact column value, returning matches and their real sheet row numbers.
- Append Row: add a new row to a sheet, keyed by header name via a single JSON row_data object.
- OAuth 2.0 connection: a single shared Google account, connected via the Kizen plugin setup assistant.
